# zclassicd documentation

Manuals for the zclassicd full node, its command-line tools and the Qt wallet: building, running, the C23 core, bootstrap snapshots, local CI and the agent guides. This is the root of the wiki that `zcl-dev wiki` walks; every directory below it is a topic and its `README.md` is the topic index.

Commands: `zcl-dev wiki`, `zcl-dev wiki agent`, `zcl-dev wiki code/src`, `zcl-dev read doc/building-quickstart.md`, `zcl-dev lessons find <query>`, `zcl-dev know <term>`, `make -C zcutil check`

Start with [building-quickstart.md](building-quickstart.md) to build, [local-ci.md](local-ci.md) to test, and [agent/README.md](agent/README.md) if you are a coding agent. The source tree is reachable as the topic `code`: `zcl-dev wiki code/src` lists `src/` with one-line summaries, and `zcl-dev read <path>` reads any file in chunks of at most 16 KiB.
